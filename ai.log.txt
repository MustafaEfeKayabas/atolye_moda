Github dan web sayfası yapmam lazım

GitHub üzerinden ücretsiz ve kolayca bir web sayfası yayınlayabilirsin. Bunun en pratik yolu GitHub Pages kullanmaktır.

Adım adım nasıl yapacağını aşağıda özetledim:

1. Adım: GitHub Repositori (Depo) Oluşturma
GitHub hesabına giriş yap.

Sağ üstteki "+" simgesine tıklayıp "New repository" seçeneğini seç.

Repository name kısmına bir isim ver (örneğin: web-sitem veya özel domain istemiyorsan doğrudan kullanici-adiniz.github.io).

Gizlilik ayarlarında Public seçeneğinin işaretli olduğundan emin ol (GitHub Pages ücretsiz hesaplarda sadece Public projelerde çalışır).

"Add a README file" kutucuğunu işaretle ve alttan "Create repository" butonuna bas.

2. Adım: Web Sayfası Dosyalarını Yükleme
Sayfanın ana dosyası kesinlikle index.html adında olmalıdır.

Oluşturduğun reponun ana sayfasındayken "Add file" > "Upload files" butonuna tıkla.

Hazırladığın HTML, CSS ve resim/JS dosyalarını buraya sürükleyip bırak.

Sayfanın en altındaki "Commit changes" butonuna basarak dosyaları kaydet.

(Eğer sıfırdan oluşturmak istersen "Add file" > "Create new file" deyip dosya adını index.html yapıp kodlarını yapıştırabilirsin.)

3. Adım: GitHub Pages'ı Aktif Etme
Deponun üst tarafındaki menüden "Settings" (Ayarlar) sekmesine tıkla.

Sol taraftaki menüden "Pages" seçeneğine gir.

"Build and deployment" başlığı altındaki Branch kısmını gör:

None yazan yeri main (veya master) olarak değiştir.

Klasör kısmını / (root) olarak bırak.

"Save" butonuna tıkla.

4. Adım: Yayına Alma
Kaydettikten sonra GitHub projenizi derlemeye başlar. Yaklaşık 1-2 dakika içinde GitHub Pages sayfasında üst tarafta sitenin linki belirir:

[https://kullanici-adiniz.github.io/repo-adiniz](https://kullanici-adiniz.github.io/repo-adiniz)

Bu linke tıklayarak sitenin canlı halini görebilirsin.
